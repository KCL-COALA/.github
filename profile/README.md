# KCL-COALA
[KCL-COALA](https://github.com/KCL-COALA) is the GitHub organisation for the COALA (Computational Corpus Annotation for Quantitative Analysis of Latin Lexical Semantics) project, lead by Dr. Barbara McGillivray and hosted by King's College London. More info about the project here: [https://coala.er.kcl.ac.uk/](https://coala.er.kcl.ac.uk/)

This GitHub organisation is meant to host codes related to our papers, as well as other pieces of software and data we want to release as part of the project's outputs.
